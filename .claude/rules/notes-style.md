# Notes style

- File names are Title Case with spaces, `.md` extension; match the existing ones.
- Use `#` headings per topic; keep sections short, bullets over paragraphs.
- Practice questions: continue the `# Question N:` numbering; never renumber existing ones. Put the answer and a one-line reason under each.
- Keep notes in the author's own voice; fix typos only when asked, don't rewrite content.
- Reference images with relative paths.
- Don't merge or split existing note files unless asked.

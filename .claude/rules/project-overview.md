# Project overview

## Layout
- `README.md` – repo purpose and exam domain weights.
- `AI Fluency Framework & Foundations.md` – notes on the 4Ds (Delegation, Description, Discernment, Diligence), generative AI basics, prompt engineering.
- `Building With Claude API.md` – numbered practice Q&A (`# Question N:`) on the Claude API.
- `Claude on Google Cloud.md` – model types, how an API call works, temperature.
- `claude-with-google.ipynb` – hands-on notebook using the Anthropic SDK (Vertex AI was not working, so it calls the Anthropic API directly).
- `image.png`, `image-1.png` – images referenced by notes.

## Purpose
Learning material, not production code. Favor accuracy and clarity over polish.

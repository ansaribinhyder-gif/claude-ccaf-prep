# Git and safety

- Branch: `main`. Commit only when asked; short imperative messages (e.g. "Add Claude Model Types documentation").
- `.env` is gitignored; never stage it. `.worktreeinclude` lists untracked files copied into worktrees.
- Never store or write PII in notes or examples (SSN, Aadhaar, PAN, passport, driver's license, credit card numbers, patient records) – org policy.
- Windows environment: PowerShell is primary; Bash also available.
